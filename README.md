# 孙勇个人学术主页（正式版｜论文一行一条易更新版）

这是正式版个人学术主页。为了便于长期维护，网站内容已经拆成两类：

- `content.js`：个人简介、研究方向、科研项目、团队、课程等
- `publications.js`：**所有论文，单独维护**

## 最常用：新增一篇论文

打开 `publications.js`，你会看到每篇论文都只占一行：

```text
年份 | 中文/英文 | 作者角色 | 论文题目 | 作者 | 期刊信息 | DOI或网页链接
```

例如：

```text
2027 | 英文 | 第一作者 | Paper title | Sun Y, Zhang X | Land Use Policy, 180: 108888 | https://doi.org/xx.xxxx/xxxxx
```

以后发表新论文时：

1. 打开 `publications.js`；
2. 复制任意一行；
3. 改成新论文的信息；
4. 保存并在 GitHub 提交。

网页会自动：

- 按年份从新到旧排序；
- 识别中文 / 英文；
- 支持“全部 / 英文 / 中文”筛选；
- 有 DOI 时显示“DOI ↗”；
- 没有 DOI 时自动隐藏链接。

### 没有 DOI 怎么办？

最后一栏留空即可，例如：

```text
2027 | 中文 | 通讯作者 | 论文题目 | 孙勇, 张三 | 地理研究, 46(2): 100–120 |
```

## 修改其他内容

修改 `content.js`。其中包括：

- 个人简介
- 研究方向
- 科研项目
- 教育和工作经历
- 研究团队 / 学生
- 课程与教学成果
- 学术兼职
- 联系方式

## 一般不要修改的文件

- `index.html`
- `style.css`
- `script.js`

除非需要改变网站结构或视觉风格。

## GitHub Pages 更新

网站上线以后，如果只是新增论文，只需在 GitHub 网页中打开 `publications.js` → Edit → 新增一行 → Commit changes。
网页通常会在很短时间内自动更新。
